# Traveling Salesman Problem — Ant Colony Optimization

Implementation of the Ant Colony Optimization (ACO) algorithm applied to the Traveling Salesman Problem (TSP), with structured experiments for parameter analysis and an interactive map visualization.

---

## Overview

The project implements the classic **Ant System (AS)** variant of ACO with **tournament selection**, evaluated on a benchmark dataset of 300 cities. Four experiment sets are provided:

| Experiment | Purpose |
|---|---|
| **A** | Baseline verification — confirms the algorithm converges |
| **B** | Alpha vs. Beta sensitivity — compares two parameter pairs |
| **C** | Evaporation rate sensitivity — compares four values of rho |
| **Final** | Full-scale test — 10, 20 and 50 cities with early stopping |

```bash
python experiments.py
```

### 2. Matplotlib visualization (tour + convergence)

```bash
python show.py
```

Runs ACO on the first `N_CITIES` of the dataset and saves a two-panel figure to `plots/show_tour.png`:
- **Left panel** — optimal tour drawn over the city scatter plot
- **Right panel** — convergence: mean distance per iteration + cumulative best

Set `SAVE_TO_FILE = False` at the top of the file to display an interactive window instead.

---

### 3. Interactive map visualization

```bash
python show_map.py
```

Runs ACO and generates `tour_map.html`, which opens automatically in the default browser. The tour is displayed over an **OpenStreetMap** tile layer via folium.

> Note: `DataSet1.csv` contains abstract normalized coordinates, not real geographic positions. The script maps them linearly to a configurable lat/lon region (`LAT_MIN/MAX`, `LON_MIN/MAX` at the top of the file).

## Parameters Reference

### `ACO` class — `aco.py`

| Parameter | Default | Description |
|---|---|---|
| `distances` | — | **Required.** Pre-computed N×N distance matrix (numpy array) |
| `n_ants` | — | Number of ants per iteration |
| `n_iterations` | — | Maximum number of iterations |
| `alpha` | — | Pheromone exponent — controls exploitation of learned trails |
| `beta` | — | Heuristic exponent — controls preference for shorter edges |
| `rho` | — | Evaporation rate per iteration, in (0, 1) |
| `Q` | — | Pheromone deposit coefficient: deposit = Q / tour_length |
| `initial_pheromone` | — | Starting pheromone on all edges |
| `tournament_size` | `2` | Candidates drawn per tournament selection step |
| `early_stopping` | `None` | Stop if best solution unchanged for this many iterations |

### Tuning guidance

| Parameter | Too low | Too high |
|---|---|---|
| `alpha` | Ignores learned pheromone (random walk) | Over-exploits early trails, premature convergence |
| `beta` | Ignores distances (poor initial solutions) | Fully greedy, no diversity |
| `rho` | Pheromone accumulates indefinitely, stagnation | Forgets quickly, slow convergence |
| `tournament_size` | More random (size=1 is purely random) | More greedy (size=N is always best-first) |

### Experiment-specific configurations

| Experiment | N cities | n_ants | n_iterations | alpha | beta | rho | Q | tau0 | early_stop |
|---|---|---|---|---|---|---|---|---|---|
| A | 5 | 10 | 30 | 1.0 | 1.0 | 0.03 | 10 | 0.1 | — |
| B | 5 | 10 | 30 | varied | varied | 0.03 | 10 | 0.1 | — |
| C | 5 | 10 | 30 | best B | best B | varied | 10 | 0.1 | — |
| Final | 10/20/50 | 20 | 500 | best B | best B | best C | 10 | 0.1 | 30 |

## `ACO.run()` return value

```python
result = aco.run()
# result is a dict:
{
    'best_tour'       : list[int],   # city indices in visit order
    'best_distance'   : float,
    'iteration_means' : list[float], # mean ant distance per iteration
    'iteration_bests' : list[float], # best ant distance per iteration
    'n_iterations_run': int,         # actual iterations (may be < n_iterations with early stopping)
    'runtime'         : float,       # wall-clock seconds
}
```

## Programmatic usage

```python
import numpy as np
from aco import ACO

# Build distance matrix from (x, y) coordinates
coords = np.loadtxt('dataset/DataSet1.csv', delimiter=',', max_rows=20)
diff   = coords[:, np.newaxis, :] - coords[np.newaxis, :, :]
distances = np.sqrt((diff ** 2).sum(axis=2))

# Run ACO
aco = ACO(
    distances=distances,
    n_ants=15,
    n_iterations=200,
    alpha=1.0,
    beta=3.0,
    rho=0.1,
    Q=10.0,
    initial_pheromone=0.1,
    tournament_size=2,
    early_stopping=30,
)
result = aco.run()
print(result['best_distance'], result['n_iterations_run'])
```
